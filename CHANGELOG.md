### Added
- Initial package structure and full source migration.
- `poset_operad.core` – atomic predicates and submatrix helpers.
- `poset_operad.decomposition` – boundary, direct-sum, and tree modules.
- `poset_operad.isomorphism` – three-tier isomorphism verification.
- `poset_operad.utils` – signatures, depth equivalents, metrics, equality.
- Comprehensive unit and integration test suite with `pytest`.
- GitHub Actions CI across Python 3.10–3.12.
- `pyproject.toml` with `ruff`, `mypy`, and `pytest-cov` configuration.
